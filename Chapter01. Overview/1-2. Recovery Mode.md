# Recovery Mode

> [!WARNING]
> **Recovery Mode 진입 전 주의사항**
>
> Recovery Mode 진입 전 보드의 전원을 완전히 종료하고, 필요한 데이터는 반드시 백업해 주세요.
> Recovery Mode 자체는 저장된 데이터를 삭제하지 않지만, 이후 진행하는 **OS 설치(Flash) 과정에서 기존 데이터가 삭제될 수 있습니다.**
>
> 또한 Flash 작업 중에는 전원 및 USB 케이블을 분리하지 마세요. 작업이 중단될 경우 시스템이 정상적으로 부팅되지 않을 수 있습니다.


<img src="pds/physicai_arm_onoff2.png" style="width:80%;">

앞선 안내와 같이 위와 같은 포트에서 5번 스위치를 통해 리커버리 모드로 들어갈 수 있습니다. 리커버리를 수행하기 위해선 C-USB 타입 케이블과 호스트 우분투 기반 PC가 필요합니다. 

보드의 전원을 끈 상태에서 스위치를 리커버리 모드로 옮깁니다. 다시 전원을 켠 후, 호스트 PC와 보드를 연결하는 6번 포트를 이용해 연결해줍니다. 

보드 종류에 따라 지정된 이미지를 업로드하여 플래싱을 진행해줍니다. 이 때, USB는 호스트 PC와 보드가 끊기지 않도록 분리되지 않게 해주시기 바랍니다.
