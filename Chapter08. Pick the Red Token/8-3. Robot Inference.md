# Robot Inference

## 실제 로봇 제어

학습된 checkpoint/model이 준비되었다면 이를 이용해 로봇을 제어합니다. 로봇이 실행 중 과하게 움직이거나 멈춰야 할 때에는 `inference_node`를 실행 중인 터미널에서 `Ctrl+C`를 눌러 노드 실행을 중단할 수 있습니다.

로봇을 실행하려면 첫 번째 터미널에서 bringup 런치 파일을 실행하고, 두 번째 터미널에서 추론 노드를 실행합니다. 로봇이 먼저 시작될 수 있도록 순서대로 각 터미널에 아래 명령어를 입력합니다.

```sh
# Terminal 1

ros2 launch physicai_arm bringup.launch.py
# 단일 로봇팔 버전(LeaderArm X): ros2 launch physicai_arm bringup.launch.py enable_leader:=false
```

```sh
# Terminal 2

ros2 run physicai_arm inference_node
```

코드를 수정하지 않고 실행할 때 파라미터로 정책 경로와 캘리브레이션 파일을 지정할 수도 있습니다.

```sh
ros2 run physicai_arm inference_node --ros-args \
  -p policy_path:=<id>/pick_red_token \
  -p top_calib_path:=./top_camera_calib.yaml \
  -p front_calib_path:=./front_camera_calib.yaml
```

노드가 실행되면 `ACT debug` 창이 열려 모델에 들어가는 top/front 이미지와 관절별 측정값·명령값을 확인할 수 있습니다. 디스플레이가 없는 환경에서는 `/inference/debug` 토픽을 이미지 뷰어(`rqt_image_view` 등)로 확인하고, 창을 띄우지 않으려면 `-p show_images:=false`를 추가합니다. 이미지 위의 빨간/초록 박스는 색상으로 찾은 토큰 후보 표시일 뿐, ACT가 선택한 목표가 아닙니다.

### 제어 흐름

1. 카메라 센서가 ROS 2 토픽을 publish
    - ROS 2에서는 각 센서가 데이터를 토픽으로 계속 publish합니다.
    - 카메라 노드는 image를, 관절 상태 노드는 joint states를 publish합니다.
2. `inference_node`가 토픽을 subscribe
    - 노드가 `/arm/top_cam`, `/arm/front_cam`, `/follower/joint_states`를 실시간으로 받습니다.
    - 최근 센서 데이터를 갱신해 추론에 사용하며, `max_age_s`(0.5초)보다 오래된 데이터로는 추론하지 않습니다.
3. observation 생성
    - 이미지를 왜곡 보정한 뒤 224x168로 줄이고, joint 값을 `ARM_JOINTS` 순서로 정렬해 ACT 입력 형식으로 변환합니다.
4. ACT policy를 이용해 action 출력
    - 현재 이미지와 로봇 상태를 종합하여 ACT policy가 다음 joint action 또는 action chunk를 예측합니다.
5. joint target을 publish
    - 출력된 값을 `/follower/joint_targets`로 publish하여 로봇에 전달합니다.
6. 로봇 움직임
    - 로봇 제어 노드가 publish된 joint target을 받아 각 관절을 제어합니다.

### 실행 전 확인 사항

- 빨간 토큰과 박스가 카메라 시야 안에 있어야 합니다.
- 토큰과 박스의 위치는 학습 데이터를 수집할 때와 비슷해야 합니다.
- 추론 입력의 이미지 크기와 joint 순서는 학습할 때와 같아야 합니다.
- `policy_path`는 학습 결과 경로(`outputs/train/pick_red_token/checkpoints/last/pretrained_model`) 또는 Hub에 업로드한 정책 저장소를 가리켜야 합니다.
- `parsing_node`에서 캘리브레이션을 적용했다면 `top_calib_path`/`front_calib_path`에도 **같은 YAML 파일**을 지정해야 합니다. 추론 노드는 파일을 찾지 못해도 경고만 출력하고 보정 없이 동작하므로, 실행 로그에 `[top] Loaded calibration`, `[front] Loaded calibration`이 출력되는지 확인합니다.

> [!TIP]
> 한 번의 시도가 끝난 뒤 다음 시도를 시작할 때는 `/inference/reset` 서비스를 호출해 ACT의 action queue를 초기화합니다.
>
> ```sh
> ros2 service call /inference/reset std_srvs/srv/Trigger
> ```
